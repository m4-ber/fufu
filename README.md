「每日任务」是一个轻量的个人打卡工具，用于每天记录和追踪自己的任务完成情况。应用分为健康、学习、任务、其他四个板块，每天由用户手动填写具体任务，点击圆圈即可标记完成。同时提供昨日回顾、周报对比和连续完成天数，帮助用户直观看到自己的坚持轨迹。
整个应用只有一个 .html 文件，不依赖任何后端、框架或外部资源，复制保存即可使用。
二、功能特性
1. 四个任务板块
· 健康：运动、作息、饮水等身体相关任务
· 学习：阅读、背单词、课程等学习相关任务
· 任务：整理、回复、待办等日常事务
· 其他：冥想、复盘、感恩记录等自由任务
每个板块独立记录，互不干扰。
2. 每日手动添加任务
· 每个板块底部有「+ 添加任务」按钮
· 输入内容后按回车或点「添加」即可保存
· 支持连续添加，适合每天早上规划当天任务
3. 任务完成打卡
· 点击任务左侧的圆圈切换完成状态
· 完成后卡片会使用该板块的主题色高亮，并显示删除线
· 完成全部任务时会有提示和轻微震动反馈
4. 任务内容可编辑
· 点击任务文字即可进入编辑状态
· 按回车或点击别处保存，按 Esc 取消
· 修改后立即生效，历史记录不受影响
5. 今日进度与连续天数
· 顶部显示今日总完成进度条和百分比
· 右上角显示连续全部完成的天数（🔥 火焰图标）
6. 昨日回顾
· 页面底部展示昨日完成数量和百分比
· 点击「展开」可查看昨日每个板块的具体任务及完成状态
· 如果昨日没有记录，会显示「昨日没有记录任务」
7. 周报与对比
· 本周总览：本周完成率、已完成任务数
· 与上周同期对比：自动计算本周与上周同一时间段的完成率差值，并用 ↑ / ↓ 标注
· 本周每日完成率：七天环形进度，今天有高亮标识
· 最近 4 周：按周展示完成率柱状图，方便看长期趋势
8. 数据保存在本地
· 所有任务和完成记录保存在当前浏览器的 localStorage
· 刷新页面、关闭浏览器后数据仍然保留
· 不上传任何服务器，隐私安全
